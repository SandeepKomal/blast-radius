    Try it without a cloud account

    The demo project uses only local Terraform resources. Run it from the blast-radius repository, then watch this page.

    cd examples/demo
terraform init && terraform apply -auto-approve
blast-radius check terraform destroy        # asks
terraform workspace new prod && terraform apply -auto-approve
blast-radius check terraform destroy        # blocked
