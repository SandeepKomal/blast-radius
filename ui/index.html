Setup checklist

In this order. Steps tick themselves off as you finish them.

    Try it safely

    The demo uses local Terraform resources only. Run it from the blast-radius repository and watch the Overview.

    cd examples/demo
terraform init && terraform apply -auto-approve
blast-radius check terraform destroy   # asks
terraform workspace new prod
terraform apply -auto-approve
blast-radius check terraform destroy   # blocked

    Useful commands

    blast-radius check '<cmd>'
    Preview any command yourself
    blast-radius config
    Print the rules in effect here
    blast-radius doctor
    Check the whole setup
    blast-radius uninstall
    Remove the hook
